# QA 术语与边界场景清单

## QA 关心的核心概念

| 术语 | 含义 |
|---|---|
| **可测性** | 验收标准能否转化为具体可执行的测试步骤 |
| **边界场景**（Edge Case）| 业务正常路径之外的极限值、首末值、空值场景 |
| **异常分支** | 用户动作失败 / 系统出错时的处理路径 |
| **Happy Path** | 主流程正常路径 |
| **Given-When-Then** | 验收标准的标准格式 |

## 常见边界场景模板

### 数据类
- 空值 / null / 空字符串
- 最大长度 / 超长输入
- 数字边界（0 / 负数 / 最大值 / 浮点精度）
- 特殊字符（emoji / 中文 / SQL 注入字符）
- 日期边界（最早允许日 / 最晚允许日 / 跨年 / 闰年）

### 状态类
- 首次操作 / 末次操作
- 临界状态（如截止前 1 秒 / 截止后 1 秒）
- 重复操作（连续点击 / 重复提交）
- 中断后恢复

### 并发类
- 同一用户多端并发
- 多用户同时操作同一对象
- 乐观锁冲突

### 权限类
- 当前用户无权限
- 跨租户访问
- 角色变更后的权限延迟

### 集成类
- 上游服务超时 / 不可用
- 数据同步延迟
- 跨模块事件失败

## 常见 PRD 可测性问题

| 问题 | 典型表现 | 反馈建议 |
|---|---|---|
| 验收标准模糊 | "系统应正确处理" | 反馈：要求改为 Given-When-Then |
| 缺失异常分支 | 仅描述 happy path | 反馈：补充失败 / 拒绝路径的验收 |
| 没有边界值 | 仅泛指"长度合法" | 反馈：明确具体边界值 |
| 状态转换没全覆盖 | 仅描述正常流转 | 反馈：补充非法转换的拒绝行为 |
| 跨 FR 冲突 | FR-A 与 FR-B 业务规则矛盾 | 反馈：要求 PM 澄清 |
