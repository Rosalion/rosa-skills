# 业务分析师术语与常见误区

## BA 关心的核心概念

| 术语 | 含义 |
|---|---|
| **用户价值** | PRD 给用户带来的可衡量收益，应能对应到客户 KPI |
| **业务流闭环** | 每条业务流程都有起点、终点、所有分支都收敛 |
| **范围蔓延**（Scope Creep）| 范围未明确导致功能不断追加 |
| **用户脑补** | PM 自己假想的用户角色，没真实业务方对应 |
| **死分支** | 流程图里画了但实际走不到的分支 |
| **缝隙 FR** | 业务流中关键动作没有对应的 FR |

## 常见 PRD 业务侧问题

| 问题 | 典型表现 | 反馈建议 |
|---|---|---|
| 价值描述空泛 | "提高效率"、"优化体验" | 反馈：要求量化（"减少 X 步骤"、"节省 Y 小时"）|
| 角色不真实 | "运营人员"无具体职责描述 | 反馈：要求确认客户内部是否有此角色 |
| 流程跨角色不清 | A 做完 B 怎么接手没说 | 反馈：补充移交点描述 |
| FR 全 P0 | 优先级失效 | 反馈：强制重排，至少 30% 非 P0 |
| 范围外只列 1-2 项 | 范围蔓延风险高 | 反馈：用 Scope Exclusion 追问补到 5+ |
