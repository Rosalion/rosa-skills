# FS 撰写常用术语表

本文档定义 fs-writer 在起草 FS 时使用的核心术语，避免歧义。

---

## 文档体系

| 术语 | 定义 |
|---|---|
| **PRD**（Product Requirements Document）| 产品需求文档。上游产物，由 prd-writer 输出 |
| **FS**（Functional Spec / Specification）| 功能规格书。**本 skill 的产出**：描述"怎么做"，含字段、表结构、状态机 |
| **功能点**（FR）| PRD 中的 FR-NNN。一份或一组紧密相关的 FR 对应一份 FS |

---

## FS 6 节模板

| 节号 | 节名 | 内容 |
|---|---|---|
| §1 | 流程说明 | Mermaid flowchart，多流程多图 |
| §2 | 功能概述 | 元数据表（功能菜单 / 功能编号 / 所属模块 / 前置后置条件等）|
| §3 | 功能界面 | 主界面 + 子界面元素清单 + ASCII 原型 |
| §4 | 关键字段说明 | 字段配置表（中英双写、业务类型）|
| §5 | 功能逻辑 | 按业务动作分组的执行步骤表 |
| §6 | 数据表结构 | 每张表一节，字段中英双写 |

可选章节（Step 3 用户主动追加才写）：
- §7 API 设计
- §8 测试用例

## 数据类型（业务类型，非具体 SQL 方言）

| 数据类型 | 含义 | 示例 |
|---|---|---|
| CHAR | 文本 | 编码、名称、描述、ID |
| NUM | 数字 | 金额、数量、百分比 |
| DATE | 日期 | 有效期至、创建日期 |
| DATETIME | 日期时间 | 创建时间、更新时间 |
| ACL | 下拉选择（引用其他表）| 公司代码、货币、风险类别；写法："参考【表名】" |
| 勾选框 | 是/否开关 | 是否冻结、是否启用 |
| JSON | 复杂结构 | 配置快照、扩展属性 |

**不使用**的类型（旧版用过，新版砍掉）：
- ❌ VARCHAR / BIGINT / DECIMAL / TINYINT 等具体 SQL 方言

---

## 触发类型（§5 功能逻辑必标其一）

| 触发类型 | 示例 |
|---|---|
| **用户操作** | 用户点击"提交"按钮、用户在表单填值 |
| **系统自动** | 状态机自动流转、级联计算 |
| **被调用** | 被上游事件触发（如寻源单发布 → 报价底稿生成）|
| **定时任务** | 每日 00:00 扫描、每小时缓存刷新 |

**关键纪律**：每个动作必标其一；四类要覆盖完整（定时任务最容易遗漏）。

---

## 字段表的列定义

§4 关键字段说明 与 §6 数据表结构都用统一的字段表格式。**字段名中英双写**：

| 字段分组 | 字段名称（中文）| 字段名称（英文）| 数据类型 | 长度 | 必填 | 取值逻辑 / 描述 |
|---|---|---|---|---|---|---|

**取值逻辑写法**：
- 手工输入 / 系统生成（按规则）/ 系统显示（取上下文）
- ACL 类型必写"参考【表名】"格式

---

## 表单类型（§6 数据表结构中标注）

| 表单类型 | 含义 |
|---|---|
| 新增配置表 | 全新的业务配置表 |
| 新增枚举表 | 字典型表（如状态、类别）|
| 新增子表单 | 已有页面下嵌入的子表单 |
| 已有表单加字段 | 在现有表上追加字段 |

---

## 编号约定

| ID | 格式 | 用途 |
|---|---|---|
| FS_<模块>_M<NNN> | FS_SRM_M001、FS_WAREHOUSE_M007 | FS 功能编号（嵌入 PRD 目录层级，如 2.3.7） |
| TC-NNN-NN | TC-001-01 | 测试用例编号（可选 §8）|

---

## 状态机（嵌在字段说明 + 功能逻辑中）

FS **不为状态机独立成章**。状态信息的位置：

- **状态值与允许的取值**：在 §4 关键字段说明的"取值逻辑"列或独立枚举表中
- **状态流转规则**：在 §5 功能逻辑的对应动作里描述（如"将状态由'已发布'改为'已停用'，此操作不可逆"）

---

## 业务规则的写作风格

§5 步骤表的"标准业务规则"列**必须是完整的中文句子**：

| 维度 | 要求 |
|---|---|
| 句子完整性 | 完整的中文句子（有主谓宾） |
| 词汇 | 中文业务术语为主 |
| 枚举值 | 用业务值（"已发布"），不用代码值（'Published'）|
| 必要英文 | 必要时在括号里附带英文名（便于开发对照）|
| 表达 | 写因果与约束 |
| 字段更新 | 用动词描述，不用赋值符号（不写 `=` `+=`）|
| 错误提示 | 原文照搬完整文案 |

详见 `memory/lessons.md` 的"标准业务规则列写作规范"。
